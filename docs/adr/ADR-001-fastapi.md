# ADR-001: Why FastAPI?

## Status

Accepted

## Date

26 June 2026

## Context

AEGIS AI requires a modern backend framework that is:

- Fast
- Easy to maintain
- Well documented
- Suitable for AI services
- Supports automatic API documentation

## Decision

We chose FastAPI.

## Consequences

### Advantages

- Excellent performance
- Automatic OpenAPI documentation
- Native type hint support
- Easy testing
- Strong community

### Disadvantages

- Smaller ecosystem than Django
- Requires understanding async programming later
